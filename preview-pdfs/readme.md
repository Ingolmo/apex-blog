## Crear el modelo de datos e importar la aplicación de ejemplo

Para poder ejecutar la aplicación sin pasos adicionales, se recomienda seguir el orden descrito a continuación.

### 1. Crear los objetos de base de datos

Ejecutar el siguiente script en el esquema donde se vaya a importar la aplicación APEX:

```sql
create table app_docs (
  doc_id      number generated by default as identity primary key,
  file_name   varchar2(255) not null,
  mime_type   varchar2(100),
  file_blob   blob not null,
  created_on  date default sysdate
);
```

### 2.Importar la aplicación APEX

1. Acceder a App Builder en el workspace correspondiente.
2. Seleccionar Import.
3. Importar el archivo de aplicación incluido en este repositorio.
4. Asociar la aplicación al mismo esquema donde se ejecutó el script SQL anterior.

Una vez importada, la aplicación estará lista para usarse.

## Qué muestra la aplicación

La aplicación de ejemplo incluye:
- Un informe con los documentos disponibles.
- Enlaces de previsualización que permiten:
    - Mostrar el PDF embebido en la propia página usando `<object>`.
    - Abrir un diálogo con un `<iframe>` para visualizar el documento de forma aislada.
- Un proceso de streaming del documento desde base de datos (BLOB) utilizando cabeceras HTTP apropiadas para visualización inline.

Estos patrones pueden reutilizarse no solo para PDFs, sino también para otros tipos de contenido soportados de forma nativa por el navegador (imágenes, SVG, etc.).

## Notas adicionales
El esquema de autenticación de la aplicación utiliza APEX Accounts.

El comportamiento exacto de la previsualización depende del navegador y de su visor integrado.

Formatos ofimáticos como DOCX o XLSX no se renderizan de forma nativa y requieren visores o servicios adicionales.

Para mantener el ejemplo autocontenido, no se utilizan librerías externas ni visores avanzados.
