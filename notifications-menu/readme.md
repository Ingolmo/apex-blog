# Oracle APEX: menú de notificaciones en la barra superior

Este repositorio contiene el **resultado exportado** de la aplicación *Notifications Menu*, creada siguiendo el ejemplo del post  
**[Cómo crear un menú de notificaciones en Oracle APEX](https://juanl.hashnode.dev/menu-notificaciones-oracle-apex)**, donde se construye un pequeño menú de notificaciones en Oracle APEX apoyándonos en componentes nativos como la **Navigation Bar List**, un **Application Item** para el contador, procesos **AJAX** y una bandeja desplegable integrada con **Universal Theme**.

> ℹ️ Una explicación paso a paso de cómo construir esta solución, entender su estructura y adaptarla a otras aplicaciones se encuentra en el post:  
> **[Cómo crear un menú de notificaciones en Oracle APEX](https://juanl.hashnode.dev/menu-notificaciones-oracle-apex)**  
> *(Este repositorio forma parte del material complementario del artículo).*

## Crear modelo e importar la aplicación de ejemplo

Para poder ejecutar correctamente la aplicación, antes de importarla conviene crear la tabla de notificaciones y cargar algunos datos de ejemplo.

### 1. Crear la tabla e insertar notificaciones de prueba

Ejecuta el siguiente script en el mismo esquema donde vayas a importar la aplicación:

```sql
create table app_notifications (
    notification_id    number generated by default as identity primary key,
    user_name          varchar2(255) not null,
    notification_title varchar2(200) not null,
    notification_body  varchar2(1000),
    target_url         varchar2(4000),
    is_read            varchar2(1) default 'N' not null
        check (is_read in ('Y','N')),
    created_at         timestamp default systimestamp not null,
    read_at            timestamp
);

insert into app_notifications (
    user_name,
    notification_title,
    notification_body,
    target_url,
    is_read
) values (
    '<YOUR_APEX_APP_USER>',
    'Invoice pending review',
    'The invoice has been generated and is waiting for validation.',
    null,
    'N'
);

insert into app_notifications (
    user_name,
    notification_title,
    notification_body,
    target_url,
    is_read
) values (
    '<YOUR_APEX_APP_USER>',
    'New support ticket assigned',
    'Ticket INC-1042 has been assigned to your queue.',
    null,
    'N'
);

commit;
```
> ℹ️ Importante: en este ejemplo las notificaciones están asociadas al valor de APP_USER. 
> Reemplaza el valor <YOUR_APEX_USER> de la columna USER_NAME para que coincida con el usuario con el que vas a iniciar sesión en la aplicación.

### 2. Importar la aplicación Oracle APEX

Una vez creado el modelo de datos e insertadas las notificaciones de prueba, importa la aplicación exportada en el mismo esquema.

### 3. Ejecutar la aplicación

Al iniciar sesión, la campana de notificaciones debería mostrar el contador de elementos no leídos. Al pulsarla, se abrirá la bandeja desplegable con las últimas notificaciones y podrás marcar cada una como leída.

## Qué incluye este ejemplo

La aplicación exportada muestra una implementación sencilla pero reutilizable de este patrón, incluyendo:

- entrada de notificaciones en la Navigation Bar List
- badge dinámico con contador de no leídas
- región compartida en página 0 para el panel desplegable
- carga de notificaciones mediante AJAX
- acción para marcar notificaciones como leídas
- enlace a una página con el listado completo

## Notas
- Este ejemplo está pensado como material de apoyo del artículo y como base para reutilizar o evolucionar el patrón en otras aplicaciones APEX.
- El enlace real del campo TARGET_URL puede adaptarse según las necesidades de cada proyecto.
- La apariencia del panel se ha ajustado para integrarse visualmente con Universal Theme.
